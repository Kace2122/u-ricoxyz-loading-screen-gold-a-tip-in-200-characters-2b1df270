One sharp, funny loading-screen tip for stressed developers and AI coding
agents, in 200 characters or fewer.

`main.py` writes the tip to `/output/entry.txt`:

> Loading tip: your AI agent already rewrote the file you were reading. Wrong file. It is very confident about this.

Run: `python3 main.py` — deterministic, same bytes on every run.
